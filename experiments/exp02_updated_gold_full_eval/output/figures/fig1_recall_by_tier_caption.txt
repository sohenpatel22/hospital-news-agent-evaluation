Figure 1: Recall by confidence tier, CEO task only. Tier A = dated announcement (n=175 gold rows), Tier B = directory-confirmed but undated (n=44), Tier C = inferred/approximate date (n=27). Limitation: recall is computed against a gold set that is itself partly derived from these systems' own outputs (see Figure 3 for the circularity control) and n is small per tier, so CIs are wide.
